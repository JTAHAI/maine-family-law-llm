# Final Architecture Summary

## Core Layers
1. Authority ingestion
2. Source registry
3. Retrieval and reranking
4. Verification pipeline
5. Draft review system
6. Filing-ready gate
7. Audit/evidence generation
8. Evaluation harness
9. Standalone API
10. Standalone UI

## Safety Principles
- Official Maine authority outranks generated text
- Review required by default
- No filing-ready output without mandatory verification
- Private matter files excluded from packaged releases
