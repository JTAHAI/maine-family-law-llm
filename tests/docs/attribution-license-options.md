# Attribution License Options

The project can be released publicly with an attribution requirement, but the final license should be selected deliberately before publication.

Practical options:

- **Apache-2.0 plus NOTICE attribution**: common for software, permissive, and supports an attribution notice file.
- **BSD-3-Clause plus attribution notice**: simple permissive software license with required copyright notice retention.
- **Custom source-available attribution license**: possible, but it needs legal review because custom terms can reduce adoption and create ambiguity.

Do not use the project license to imply any license over official Maine source snapshots, commercial legal commentary, court forms, or attorney-reviewed private evaluation records. Those external materials stay outside the source repository and are governed by their own terms.

Recommended path for this repo: start with Apache-2.0 plus a clear `NOTICE`/attribution file after legal review, unless the release owner specifically needs a stricter custom attribution license.
