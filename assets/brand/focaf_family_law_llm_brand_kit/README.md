# FOCaF Maine Family Law LLM Brand Kit

This ZIP contains a drop-in For Our Children & Families branding package for the Maine Family Law LLM project.

## Start here

1. Open `brand-guide.html` for the visual guide.
2. Open `examples/llm-screen.html` to preview the styled app surface.
3. Copy `css/focaf-family-law-llm-theme.css` into the other project.
4. Copy `assets/logo/` and `assets/favicon/` into the public assets directory.
5. Add the contents of `snippets/favicon-head.html` to the app `<head>`.

## Files

- `BRAND_GUIDE.md` — full written style guide.
- `brand-guide.html` — visual guide.
- `css/focaf-family-law-llm-theme.css` — full drop-in CSS.
- `data/design-tokens.json` — portable tokens.
- `data/palette.json` — palette and usage notes.
- `assets/logo/` — SVG mark, horizontal lockup, and wordmark.
- `assets/favicon/` — favicon SVG/PNG/ICO and manifest.
- `assets/social/` — social/OpenGraph card in SVG and PNG.
- `examples/llm-screen.html` — static branded app mockup.
- `snippets/react-brand-shell.tsx` — React component snippets.

## Boundary copy

Recommended UI sentence:

> This tool provides Maine family-law research from retrieved source snippets. It does not create an attorney-client relationship, does not replace review by a qualified professional, and does not accept private case intake.
