# Pass 01 Build 2 — Windows VBS Launcher Hotfix

## Defect

Double-clicking `START_MAINE_FAMILY_LAW_LLM.vbs` produced Windows Script Host error `800A0409` at line 3 because the command used an unterminated nested quote sequence.

## Repair

The launcher now:

1. resolves its own directory with `Scripting.FileSystemObject`;
2. builds the CMD path with `BuildPath`;
3. resolves the Windows command processor through `%ComSpec%`;
4. constructs command quotes with `Chr(34)` instead of embedded quote runs; and
5. launches asynchronously in a normal window.

The same implementation is generated by `bootstrap_repository`, preventing future corpus/bootstrap packages from recreating the malformed launcher.
