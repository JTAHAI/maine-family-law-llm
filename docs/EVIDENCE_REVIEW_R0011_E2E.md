## Quality boundary and release truth

The raw adapter is **not a reliable standalone answerer**. On the older
free-wording regression, it passed only **5/12** aggregate mechanical cases:
source-reference checks were 12/12, quote binding 10/12, meaning checks 7/12,
and forbidden-literal checks 11/12. Manual review also found that a derivative
copy explanation could reverse the direction of derivation when record order
changed. Those findings are why raw narrative is never shown.

This result proves one useful and safe product path: the adapter can propose
record excerpts, the deterministic host verifies them against approved private
records, and the UI exposes only exact verified spans with review-required
status and provenance. It does **not** establish substantive Maine-law accuracy,
attorney review, production admission, frozen-app or installed-MSIX reachability,
Store readiness, Enterprise GA, or filing use.

Remaining release gates are independent human evaluation, production-signed
admission for the exact pack hashes, a stronger free-wording evaluation result,
target-PC memory and latency qualification, frozen/package verification, and a
clean full regression.
