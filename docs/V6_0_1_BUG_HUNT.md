# v6.0.1 Bug Hunt

## Scope

This pass corrects reproducible defects without changing the established navigation, legal workflows, source lanes, filing gates, or v6 visual system.

## Corrected boundaries

1. Filesystem containment uses resolved path components rather than string prefixes.
2. Release ZIP names are basenames only on every operating system.
3. Evidence references admit only bounded opaque IDs, HTTPS, or URN forms.
4. Release signoff timestamps must include a timezone.
5. Safety-sensitive API booleans are strict JSON booleans.
6. API modules remain importable without optional API packages.
7. Reduced-motion users do not receive forced smooth scrolling.

## Explicit non-claims

The pass does not provide attorney participation, a real-matter pilot, signed packaging, WACK certification, Store approval, production deployment, or GA shipment evidence.
