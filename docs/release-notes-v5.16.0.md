# Maine Family Law LLM v5.16.0 — Attorney Sandbox Operations

v5.16.0 implements the operational infrastructure for the attorney-only sandbox stage.

- Adds deterministic public/synthetic review programs and question-queue hashes.
- Adds eligible-reviewer cohorts and bounded review assignments.
- Adds structured attorney review receipts with five ratings, finding codes, response hashes, and verifier hashes.
- Requires full assignment coverage before a sandbox session can be completed.
- Adds controlled feedback triage and remediation/retest evidence requirements.
- Adds review-required eval-candidate exports that never count automatically as attorney gold.
- Adds immutable Pass 48 operations evidence packets and short-lived opaque downloads.
- Adds the Pass 48 operations controls to the Release & Pilot workbench.
- Preserves the rule that the application cannot verify licensure, accept real matter data, or close Pass 48 by itself.

Product version: **5.16.0**. Microsoft Store package target: **5.16.0.0**. UI build: **43**.
