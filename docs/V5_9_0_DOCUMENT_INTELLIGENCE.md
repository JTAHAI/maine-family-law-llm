# v5.9.0 Document Intelligence Workbench

## Purpose

The verified local source inspector can create structured document blocks, compare privacy detectors, and generate a separate searchable PDF preservation copy without modifying original evidence.

## Host-controlled pipeline

1. Resolve an opaque record capability against the active matter.
2. Re-hash the verified source or archive member.
3. Enforce regular-file, containment, symlink, type, and size rules.
4. Produce deterministic baseline blocks.
5. Optionally run Docling in an offline subprocess when installed.
6. Run deterministic privacy patterns and optionally compare Presidio results.
7. Store a hash-bound report under the matter-local document-intelligence area.
8. Return a short-lived, matter-scoped artifact capability rather than a filesystem path.

## OCR preservation

OCRmyPDF runs only after explicit approval and only for a verified PDF. It creates immutable content-addressed PDF, sidecar-text, and receipt artifacts. The original is re-hashed after the tool completes; any source change blocks the result.

## Safety statements

- Document structure is a review aid, not proof of authenticity or legal significance.
- Automated privacy detection may miss sensitive information.
- OCR may contain substitutions, omissions, or layout errors.
- Retrieved document instructions cannot change application policy.
- Optional components are never installed or downloaded automatically.
- Model licenses used by Docling require separate review before distribution.
