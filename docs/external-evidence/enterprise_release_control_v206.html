Enterprise Controls

Official Maine authority

Live official-source manifests, parsed authority, retrieval indexes, and freshness reports must live outside the source repo.

Legal quality gates

Citation, quote-span, claim-support, staleness, jurisdiction, and form-freshness metrics must pass from accepted external evidence.

Attorney review

Attorney sandbox and limited pilot reports must be signed externally with reviewer, consent, and incident fields.

Matter privacy

Private matter data must stay outside the repo, outside shared-model training by default, and inside isolated encrypted stores.

Security and governance

Security, governance, incident, audit, rollback, and maintenance evidence must be approved before RC signoff.

Deployment and operations

A clean deployment, source ZIP, external data manifests, runbooks, rollback package, and owner signoff must exist.

Ship

pass48_attorney_sandbox

Run an attorney-only sandbox with public/synthetic prompts, verify reviewer bar status, complete onboarding, review the feedback queue, and sign the external attorney_sandbox_pilot_report.json.

pass49_limited_real_matter_pilot

Run a limited real-matter pilot only with explicit consent, tenant isolation, encryption, daily review, attorney signoff, zero leakage, and zero unsupported filing-ready exports.

pass50_release_candidate

Freeze a release-candidate artifact inventory and collect security, legal, product, and ops approvals with zero open P0/P1 blockers.

pass51_ga_shipment

Ship only after the RC passed, clean deployment and external manifests exist, all GA controls are true, and ga_shipment_signoff.json is signed.

run_fail_closed_gate

Run scripts/run-pass48-51-launch-evidence-gates.py against the external pilot and release roots with --require-ready.

preserve_repo_boundary

Do not commit private matter data, source corpora, parsed authority stores, retrieval indexes, eval stores, model weights, runtime DBs, or .env files.

Enterprise release control is a fail-closed operator workflow. It does not create attorney review, legal signoff, pilot evidence, production deployment, or GA shipment evidence. The release is enterprise_ready only when the external Pass 48-51 launch evidence gate passes with real signed artifacts.
