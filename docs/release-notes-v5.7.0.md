# Maine Family Law LLM v5.7.0 — Revision-Bound Evidence and Filing Review

v5.7.0 turns the drafting workspace into a review workbench. A reviewer signs the exact revision and the exact reports—not a mutable screen state.

## User capabilities

- Enter material facts one per line and map them to bounded, already-indexed private-record spans.
- Prepare a packet that binds the current revision hash, authority-verification result, fact-to-record report, and filing-gate preflight.
- Record review complete, request changes, or reject the draft.
- See every remaining filing blocker inside the main document workspace.
- Review an append-only local decision history and verify its hash chain.

## Safety boundary

- A record-text match does not prove authenticity, credibility, intent, contempt, or another legal conclusion.
- Review packets become stale immediately when the document revision changes.
- Approval requires a one-use capability and explicit attestation.
- A reviewer decision cannot override unresolved filing blockers.
- Reviewer identity is a local user-entered record; the application does not independently validate licensing.
