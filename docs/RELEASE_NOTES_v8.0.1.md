# Maine Family Law LLM 8.0.1

This maintenance update strengthens the existing local research, record review,
drafting, privacy, and model-management workflows. It preserves the Store identity,
publisher, x64 architecture, and en-us language. Existing matter storage formats
are unchanged; no private data is migrated into the source tree or package.

Changes include source-bound specialist instructions and reference checks,
bounded worker memory, safer cancellation and restart behavior, authority and
evidence traceability repairs, and more reliable production navigation. New build
output and caches stay under repository dist. Regression runs use sequential
fresh processes and account for every collected test and every skip.

The package does not include newly trained legal specialists. The latest separate
evidence-review research adapter completed a 25,600-example fictional-record run,
but its fresh evaluation currently reports 6/12 checks passed and its own metadata
sets production admission and RC completion to false. The seven r0004 workflow
adapters are also development-only. Both remain excluded. Model import still
requires the exact licenses, hashes, compatibility policy, and signed admission.

All legal work remains review-required. This maintenance version is not a claim
of attorney approval, pilot completion, Store certification, or Enterprise GA.
The exact package qualification results belong in the accompanying release
evidence, not inferred from the version number.
