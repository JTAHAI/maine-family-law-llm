# Maine Family Law LLM v8.0.0

v8.0.0 adds twenty fully local, matter-scoped workbench verticals. Each runs through the canonical API and shipped desktop UI, stores private artifacts encrypted at rest, preserves source hashes and exact-result receipts, and requires an immutable human review decision.

## New verified workbenches

- Offline native audio transcription with bundled, hash-pinned whisper.cpp 1.9.2 and a compact English model.
- OCR correction history, communications import, evidence relationships, local-model admission, current-form working copies, table extraction, and financial-document review.
- Order comparison, authority-build inspection, guided research planning, evidence annotation, local scheduling, encrypted reviewer handoff, and reusable matter templates.
- Entity resolution, local corrective-action notifications, offline courtroom bundles, source-bound voice drafting, and signed-extension permission controls.

## Enterprise-grade controls

- Matter and tenant isolation with role enforcement on every canonical route.
- Encrypted state and artifacts, hash-verified artifact access, and append-only audit history.
- Idempotent request support, fail-closed native dependencies, bounded inputs, path containment, and no automatic runtime download.
- Exact-result drill-down, artifact receipts, visible review-required status, and immutable accepted/needs-changes/rejected decisions.

## Safety boundary

All generated outputs remain review-required work product. Add-ons do not file with a court, determine legal conclusions, send private data, activate authority builds, or make a result filing-ready by themselves. Enterprise organizational validation, legal sign-off, or controlled-pilot approval is not claimed by this engineering acceptance.
