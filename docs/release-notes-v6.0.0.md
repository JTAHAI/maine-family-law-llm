# Maine Family Law LLM v6.0.0 — Visual Design Refresh

v6.0.0 gives the established local-first family-justice workbench a new major-release visual identity without rebuilding its workflows or navigation.

## Visual system

- Atlantic, pine, tide, warm-paper, gold, and berry palette.
- Updated system typography using Segoe UI Variable/Aptos fallbacks; no remote fonts.
- More consistent spacing, radii, shadows, borders, and interaction states.
- Unified treatment for chat, evidence cards, side rails, review workspaces, and all existing modals.
- Refined header, control bar, composer, primary actions, status badges, and footer.
- New visual-generation marker and visible v6 refresh chip.

## Accessibility

- Three-pixel visible focus treatment.
- Reduced-motion behavior.
- Increased-contrast mode support.
- Windows forced-colors support.
- Accessible semantic structure and established keyboard behavior retained.
- No workflow, control ID, API path, or local/privacy boundary removed.

## Release identity

Product version: **6.0.0**
Microsoft Store package target: **6.0.0.0**
UI build: **47**

This is a source release. A signed Windows package, WACK result, Store approval, and legal GA evidence remain external qualification items.
