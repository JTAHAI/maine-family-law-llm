# Maine Family Law LLM v5.17.0 — Limited Real-Matter Pilot

v5.17.0 adds the controlled operations layer for a limited, named-tenant real-matter pilot while preserving the product's local-first, review-required, fail-closed legal safety boundaries.

## Added

- External, hash-chained Pass 49 operations ledger.
- Named tenant allowlist and external Pass 48 evidence binding.
- Opaque real-matter enrollment with consent, privacy, isolation, encryption, matter-store, and retention evidence hashes.
- Required work-product hash inventory.
- Daily human-review and usefulness records.
- Restricted-export attempt records.
- Incident lifecycle with containment, remediation, retest, and permanent leakage/cross-matter blockers.
- External attorney signoff references.
- Deterministic JSON, HTML, receipt, and manifest evidence packets.
- Eleven local API paths and integrated workbench controls.
- Tamper, path, symlink, private-text, training-use, unsupported-export, and cross-tenant regression tests.

## Not claimed

- No real participant or matter is bundled.
- No client consent or attorney signoff is independently verified by the application.
- No private matter data is included in source artifacts.
- No Pass 49 completion, legal GA, Store certification, or filing-ready status is claimed.
