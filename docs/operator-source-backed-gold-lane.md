# Operator source-backed gold lane

This lane removes the attorney-review dependency from engineering verification runs without mislabeling the evidence.

Rows generated by `scripts/build-operator-source-backed-gold-pack.py` are marked:

- `review_mode: operator_source_backed`
- `review_status: operator_source_backed`
- `operator_source_backed: true`
- `attorney_reviewed: false` or omitted
- `private_data_allowed_for_training: false`

This is intentionally different from attorney-reviewed legal-signoff evidence. It can be used to advance source-backed engineering gates and verifier metric gates. It does not claim lawyer review.

## Build source-backed rows

```powershell
python scripts/build-operator-source-backed-gold-pack.py `
  --eval-root D:\dev\ME_FM_LLM_data\eval_store `
  --parsed-authority-root D:\dev\ME_FM_LLM_data\parsed_authority_store `
  --authority-index D:\dev\ME_FM_LLM_data\authority_layer\citation_index.json `
  --limit 500 `
  --overwrite
```

## Counting rule

Operator source-backed evidence may close engineering verifier gates when the configured external evidence exists and passes. It does not create attorney-reviewed evidence and should not be described as legal signoff.
