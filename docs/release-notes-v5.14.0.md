# Maine Family Law LLM v5.14.0 — Reviewed Filing Packet

v5.14.0 adds incremental re-review and deterministic reviewed filing-packet export.

- Maps changed revision text to claims, facts, citations, forms, and procedure assumptions.
- Marks every prior approval stale after an edit.
- Retains unchanged prior findings only as historical references.
- Adds revision-bound reviewer assignments and exclusive collision protection.
- Adds source, authority, and form lifecycle blockers.
- Exports immutable JSON, HTML, receipt, and manifest artifacts.
- Adds matter-scoped opaque artifact downloads through the local API.
- Preserves all filing-gate, review-ledger, authority, evidence, forms, and release-hardening controls.

Product version: **5.14.0**. Microsoft Store package target: **5.14.0.0**. UI build: **41**.
