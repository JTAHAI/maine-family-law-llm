Maine Family Law LLM Privacy Policy

Effective date: July 17, 2026

Maine Family Law LLM is a local-first legal-information and record-organization workbench. It is not legal advice, and its outputs remain review-required.

What files the app can access

The app can access files and folders that the user selects for corpus intake, review, export, or verification. The Microsoft Store edition does not require broad machine scanning by default.

How local files are used

When a user selects source folders or files, the app hashes and inventories the originals read-only, builds derived indexes and review packages in a separate user-selected workspace, and preserves source-verification metadata.

Where local state is stored

The Microsoft Store runtime stores local application state under %LOCALAPPDATA%\MaineFamilyLawLLM. This may include:

  • local launcher state
  • selected active corpus information
  • local service state
  • runtime logs
  • temporary fictional demonstration outputs used for smoke testing

Actual matter or corpus builds remain in a user-selected external folder and are not stored inside the installed package directory.

Telemetry and data transmission

The Microsoft Store packaging path does not add telemetry. If the application is used in its default local-first mode, it does not send user matter data to a remote service.

If a user later modifies the open-source project to enable optional third-party APIs or model lanes, those changes are outside the default Microsoft Store package and follow the operator's own configuration and the third party's policies.

Training and shared models

Private matter files are not used for shared-model training by default in this Microsoft Store package.

How to delete local data

  • Delete local app state under %LOCALAPPDATA%\MaineFamilyLawLLM.
  • Delete any user-created external matter or corpus folders separately.
  • Uninstalling the app removes the package but does not automatically delete user-created external matter folders.

User responsibilities

Users remain responsible for:

  • choosing appropriate source folders
  • reviewing privacy, privilege, and sensitivity risks before sharing a package
  • using official court records and qualified legal review where required
  • securing exported matter folders and USB packages

Security limitations

No local desktop application can guarantee perfect protection against device compromise, insecure file sharing, or operator error. Users should protect their Windows account, storage device, and exported packages appropriately.

Affiliation disclaimer

Maine Family Law LLM is not affiliated with the Maine Judicial Branch, any Maine court, or any government body.
