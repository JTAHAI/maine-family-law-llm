# Sample evidence artifacts

This folder contains historical, non-production evidence JSON captured during earlier local hardening passes. These files are examples only.

Current release and smoke evidence should be regenerated by scripts into an operator-selected output path or external evidence root. Generated JSON should not live at the repository root, and a strict local doctor now treats root-level generated evidence JSON as repo contamination.

These samples do **not** prove production legal GA, live official Maine authority ingestion, attorney-reviewed gold evals, pilot readiness, security signoff, or filing-ready legal use.

Most local smoke/evidence scripts now default here instead of the repository root. Use an explicit external evidence path for real release evidence.
