# Attorney sandbox review packet

This packet describes what a future attorney sandbox review should contain. It is not evidence that review has happened.

Each review packet should include:

- `answer_id`
- `audit_trace_id`
- mode and audience
- workflow id
- redacted user prompt
- output text
- full response contract JSON
- sources used
- citation, quote, and claim-support statuses
- red flags and missing information
- filing-ready status
- reviewer questions and feedback fields

The packet must stay review-required until real reviewer feedback is attached. Passes 48-51 remain open until external pilot and signoff evidence is supplied to the existing gates.
