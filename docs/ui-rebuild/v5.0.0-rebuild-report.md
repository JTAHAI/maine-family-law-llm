# Maine Family Law LLM v5.0.0 UI rebuild and UX-hardening report

## Scope

This release rebuilds the local browser workbench around the approved premium family-justice design and hardens it across desktop, compact-window, tablet, and phone sizes. It does not add external model providers or MCP orchestration. Existing local-first legal research, private-record, OCR, corpus, evidence, review, printables, and secure record-opening behavior remains the functional baseline.

## Visual confirmation

At 1440×1080 the rebuilt interface closely matches the approved design structure and visual language: deep-navy FOCAF identity header, Local only status, top context controls, three-column workbench, source-lane chat, persistent research rail, evidence drawer, clickable record cards, composer controls, and privacy/review footer.

Responsive layouts intentionally reflow rather than compress the desktop design:

- Full workbench at 1360 px and wider.
- Compact chat + inline evidence at 960–1359 px.
- Full-width chat + modal evidence drawer below 960 px.
- Additional phone compaction below 720 px and 480 px.

## UX hardening

- Dynamic viewport-height support and short-height handling.
- No horizontal page overflow at nine audited viewport sizes.
- Resize-aware drawer state with user preference preservation.
- Drawer focus return, backdrop behavior, scroll locking, and synchronized ARIA state.
- Mobile access to Privacy, Matter, and Evidence & tools while dense settings remain available through Conversation settings.
- Reduced-motion and forced-colors support.
- Overscroll containment, wrapping safeguards, and resilient min-width/min-height rules.
- Identical packaged and source UI assets.
- Build cache incremented to v5.0.0-b25.

## Validation

- 278 focused regression tests passed; 1 platform-appropriate test skipped.
- Nine Chromium resize audits passed from 1440×1080 through 390×844.
- Zero horizontal-overflow failures.
- JavaScript syntax and Python compilation passed.
- Browser rendering produced no page errors or starter-library load errors.

## Deferred

- Windows MSIX build, signing, WACK, and Store submission.
- Prefrontal Node and external MCP provider integrations.
