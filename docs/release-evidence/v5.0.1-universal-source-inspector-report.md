# Maine Family Law LLM v5.0.1 validation report

Version 5.0.1 adds a universal, local-only source inspector for the active private corpus. The workbench can now inspect PDFs, images, emails and attachments, text and office documents, tables, ZIP members, and supported local media through opaque, expiring capabilities. Original files remain read-only and filesystem paths are never returned to the browser.

## Security and UX changes

- Random 256-bit record capabilities replace deterministic open tokens.
- Capabilities expire, are bounded in memory, and remain scoped to the active corpus.
- Every opened source is checked against the indexed SHA-256 hash.
- HTML, SVG, XML, and script-like content cannot execute inside the local application origin.
- Email HTML is reduced to safe text; attachment inspection remains separately tokenized.
- PDFs open at the matching page inside the inspector, with previous/next controls.
- Images support fit and zoom without modifying the original.
- Office and text formats use bounded local extraction; CSV and TSV use bounded table previews.
- ZIP members receive separate secure inspection/open capabilities.
- The inspector resizes on desktop and becomes a full-screen sheet on small windows.
- Keyboard users receive focus trapping, Escape/backdrop close, and focus return.
- The MSIX build script now skips Git metadata collection cleanly when building from a source ZIP without a `.git` directory.

## Validation

The focused release suite passed 180 tests. The v3-v5 version, UI, corpus, OCR, drill-down, source-preview, and v5.0.1 inspector suites account for 137 passing tests. JavaScript syntax, Python compilation, OpenAPI generation, UI mirror parity, API mirror parity, data-boundary checks, public-repository integrity, release-artifact hygiene, and Store packaging tests passed.

The complete repository suite is not claimed as completed in this Linux container: a Tk launcher test requires a graphical display, and several enterprise data-product suites exceed the available execution window. The Windows MSIX remains a release-machine step.
