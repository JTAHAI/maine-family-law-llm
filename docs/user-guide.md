# User Guide

The Maine Family Law LLM is a review-required research and drafting assistant. It helps ask Maine family-law questions, review documents, map facts to evidence, create timelines, inspect citations and quotes, and prepare working drafts.

Every legal answer should show source cards. Every draft remains review-required unless all authority, citation, quote, fact, posture, form-freshness, and human-review gates pass.
