# Security Policy

This repository is a source-code package for the Maine Family Law LLM project. Do not publish private matter files, official-source snapshot corpora, parsed authority stores, embeddings, model weights, runtime databases, attorney-reviewed gold data, secrets, or production credentials in this repo.

## Reporting security issues

Open a private security advisory or contact the maintainers through the private project channel. Do not include client facts, sealed records, juvenile records, privileged material, or credentials in a public issue.

## Production legal readiness

A clean public source release is not a legal-production certification. Production use remains blocked until real external official authority, attorney-reviewed evals, measured metrics, pilot/security evidence, and owner signoffs pass the gates.
